# 9-in-1-elections

台灣地方選舉選情分析小工具。第一版聚焦 2026 年台北市長選舉，以可追溯的公開資料呈現民調支持度、民調趨勢與歷史選舉結果。

> 本專案目前處於規劃階段。以下技術架構與功能是規劃方向，尚不代表已完成實作或部署。

## 專案目標

提供來源清楚、可查證的選情觀察儀表板，協助使用者檢視民調及歷史資料。民調支持度是調查結果，不代表勝選機率或已驗證的得票預測。

## 第一版範圍

- 以台北市長選情為主，呈現有來源的民調、趨勢與歷史選舉結果。
- 以 React、Vite 與 TypeScript 建置前端，資料使用版本控制中的靜態 JSON。
- 規劃部署於 Cloudflare Workers Static Assets；Cloudflare Drop 僅供短期預覽。
- 青年投票率情境試算僅在資料、公式及假設完整且可追溯時啟用；條件未滿足時應停用並說明缺項。
- 第一版不包含即時爬蟲、登入、後端 API、資料庫、勝選機率或未經驗證的綜合預測。

## 資料與呈現原則

- 每筆民調保留來源、調查日期、機構及調查情境，並連結原始報告。
- 候選人組合、調查母體或題目情境不一致的民調，不得混成同一趨勢線。
- 不以插值或平滑補出不存在的民調資料；資料不足時明確標示。
- 測試資料須在資料及介面上標示為模擬資料。
- 公開資料前核對來源使用條款及必要標示；無法確認可否重製時，不公開擷取數值。
- 情境結果須顯示輸入資料、假設及公式版本，並標示「情境試算，非選舉預測」。
